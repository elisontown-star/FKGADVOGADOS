Integração Biometria (Control iD)

Conecte o equipamento biométrico da entrada para marcar presença automaticamente ao bater o dedo.

1. URL do Webhook

Configure esta URL no equipamento em Configurações → Monitor (hostname/porta/path), ou informe ao seu técnico de TI.

O secret é gerado automaticamente na primeira vez que você abrir esta tela. Gerar um novo invalida a URL anterior.

2. Código de evento "acesso concedido"

Cada modelo pode reportar um código numérico diferente para "acesso concedido". Bata o dedo no equipamento uma vez e veja no log abaixo qual valor aparece no campo event — depois cole aqui (pode ter mais de um, separado por vírgula).

3. Mapear colaboradores

Associe o ID de usuário do equipamento (visível no log abaixo após o colaborador bater o dedo) ao nome correspondente no sistema.

4. Últimos eventos recebidos
